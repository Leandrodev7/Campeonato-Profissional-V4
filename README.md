Campeonato Profissional V4

Sistema web para organizar e acompanhar campeonatos de futebol.

Acessar o projeto

- Aplicação publicada: https://campeonatoprofissional.netlify.app/
- Repositório no GitHub: https://github.com/Leandrodev7/Campeonato-Profissional-V4

Funcionalidades

- Painel com resumo da competição.
- Cadastro e gerenciamento de times.
- Classificação do campeonato.
- Rodadas, jogos e resultados.
- Artilheiros.
- Gerenciamento de temporadas.
- Backup dos dados.
- Integração com Supabase para persistência dos dados.

Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Supabase

Sobre o projeto

Este projeto faz parte do meu portfólio de estudos em desenvolvimento web. Foi desenvolvido para praticar a construção de uma aplicação com interface, regras de negócio, gerenciamento de dados e integração com um serviço de banco de dados.

O projeto continua em evolução, com foco na organização do código, na confiabilidade dos dados e na experiência de uso.

Executar localmente

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Execute o arquivo "index.html" com uma extensão como Live Server.

Observação: os recursos que dependem do Supabase precisam da configuração correspondente do projeto.
